# ✨ Shine Coaching — Learn Today, Shine Tomorrow!

**A brighter way to learn, grow, and succeed.** 📚

Welcome to **Shine Coaching**, a student-friendly educational website designed to help parents and students explore learning programs, discover our teaching approach, and connect with the coaching centre easily.

---

## 🌟 About Shine Coaching

Every student deserves the right guidance and personal attention. Shine Coaching focuses on building strong concepts, encouraging daily practice, and making learning easier for young learners.

Our website provides useful information about our coaching centre, courses, and contact details in a simple and accessible format.

## 🎯 Our Learning Programs

| Program | Learning Focus |
|---|---|
| 📘 Classes 2–7 | Strong basics, regular practice, and concept building |
| 🧸 LKG | Fun learning, ABCs, colours, and shapes |
| 🎨 UKG | Early learning, numbers, language, and basic skills |

## 💡 What Makes This Website Special?

- 🏠 **Home Page** — Discover Shine Coaching and its learning approach.
- 👩‍🏫 **About Page** — Learn more about the coaching centre.
- 📚 **Courses Page** — Explore available classes and programs.
- 📞 **Contact Page** — Find contact information and location details.
- 🌐 **Language Options** — Switch between Hindi and English pages.
- 📱 **Responsive Design** — Designed to work across different screen sizes.
- 🎨 **Clean Interface** — Simple navigation and an attractive layout.

## 🛠️ Built With

- **HTML5** — Website structure
- **CSS3** — Styling and page layout
- **Font Awesome** — Icons for a better visual experience

## 🚀 How to Run

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Ensure all HTML, CSS, and image files are present.
4. Open `index-en.html` in your browser, or use Live Server.
5. Explore the website using the navigation menu.
