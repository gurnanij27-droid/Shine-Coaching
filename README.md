# Shine Coaching Website

## About the Project
Shine Coaching is a simple and user-friendly website created to provide information about the coaching centre. It helps parents and students learn about available courses, teaching methods, and contact details.

## Objectives
- To provide information about Shine Coaching.
- To display available courses for Classes 2–7, LKG, and UKG.
- To help parents contact the coaching centre easily.
- To create a simple and responsive website.

## Website Pages
1. **Home:** Introduction to Shine Coaching and its features.
2. **About:** Information about the coaching centre.
3. **Courses:** Details of available classes and learning programs.
4. **Contact:** Contact details and location information.

## Features
- Simple and attractive design.
- Easy navigation between pages.
- English and Hindi language options.
- Course information for different classes.
- Contact details for parents and students.
- Responsive layout for different screen sizes.

## Technologies Used
- HTML5
- CSS3
- Font Awesome

## How to Open the Website
1. Download the project files.
2. Keep all HTML, CSS, and image files in the same project folder as required.
3. Open `index-en.html` in a web browser.
4. Use the navigation menu to explore the website.

## Project Purpose
This website was developed as a BCA web development project to practise HTML and CSS and provide an online presence for a local coaching centre.

## Conclusion
The Shine Coaching website makes it easier for parents and students to explore courses and find important information about the coaching centre.
